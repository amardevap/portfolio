# Amardev AP — Portfolio

Static site. Deploy on Vercel:

1. Push this folder to a GitHub repo, then import it in Vercel (New Project). No build step is needed.
   Or run `npx vercel` inside this folder and accept the defaults.
2. Open the deployed URL. The intro loops at the top, and the sections below are tap-to-play.

Files:
- index.html — the whole page (HTML, CSS, JavaScript)
- assets/intro.mp4 — the intro video
- assets/sea.jpg — the underwater background

Edit mode (the "Edit page" button) saves uploads, rows, colours and text in the browser
of whoever edits. Those changes are not written back into this folder.
